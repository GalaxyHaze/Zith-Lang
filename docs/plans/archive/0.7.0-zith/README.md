# Archived: Zith 0.7.0 Full-Zith Steps

This directory contains the old execution plan for a 0.7.0 full-Zith release:
comptime, generics, traits, introspection, type construction and the
capability base.

It is preserved for history and design reference. The compiler product split
now keeps family language features inside the full Zith spec and moves the
active `Zith--` planning to `docs/plans/0.7.0/`. The trait, generic,
conformance and generic-constraint portions that were implemented in the
refreshed plan are recorded as Working in `docs/impl-status.md`.

Do not treat these step files as the current execution plan for `Zith--`.
Feature IDs are still referenced by the roadmap.
