# Documentation
Zith and Zith-- are sibling systems languages with separate specifications and language contracts. **Zith** is documented by its language-design reference. **Zith--** is the language currently implemented by the `zithc` compiler.

## Choose a Language
* **Zith:** Documents the Zith language design. It does not describe the behavior of `zithc` and is not a roadmap for Zith--.
* **Zith--:** Documents the language and compiler contract you can use with `zithc` today.

## How They Relate
They are separate languages, so Zith-- will not evolve into Zith. A feature listed in one reference is not automatically part of the other, and the implementation status of each language is independent. This section also covers installation, CLI usage, and the current Zith-- implementation status.
