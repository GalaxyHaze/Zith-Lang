# Zith Documentation

This documentation covers two closely related language layers. **Zith** is
the complete language design and specification. **Zith--** is the implemented
subset that the current `zithc` compiler can check and build.

## Choose a documentation set

Start with the [Zith documentation](route:zith) to read the full language
design, specification, and implementation status.

Choose the [Zith-- documentation](route:zith--) when writing programs for the
current compiler. It covers the supported syntax, practical guide, and subset
reference.

## How they relate

Zith describes the intended language. Zith-- is the part available in the
compiler today, so a feature in the Zith specification is not necessarily
usable in a Zith-- program. The implementation status page records that
boundary.
