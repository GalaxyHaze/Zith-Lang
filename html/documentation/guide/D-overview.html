Zith-- Language Guide

This guide is the practical entry point to Zith--. The main compiler builds the subset documented in the English Zith-- reference. the larger language design is separated into the Zith reference.

Learn the working language

Read these pages in order when learning the core:

  • Syntax for expressions, operators, and literals.
  • Bindings for let, var, and const.
  • Types for structs, pointers, slices, and dyn.
  • Functions for declarations, overloads, and raw fn.
  • Control Flow for branches, loops, and when.
  • Modules for imports and visibility.

Then continue with Generics, Traits & Interfaces, and C Interop.

Read boundaries before using advanced features

Memory Model, Errors, Comptime, Contexts, Words & Macros, Concurrency, and Raw & Unsafe include features with explicit implementation boundaries. Each page separates what works in Zith-- from what remains full-Zith design material.

When an example needs a feature that is not implemented, the page links to the formal reference instead of presenting that example as runnable code.
