# Idea Lifecycle Local Tracker

This directory is the local tracker for active ideas during setup. It is kept
small on purpose: one feature, one idea, one lifecycle at a time.

Do not use this directory as a general backlog. It holds the current idea in
flight, the pointer to its plan, and the signed promise ids when the idea
reaches signing.

Read `docs/agents/idea-flow.md` before adding an idea here.
